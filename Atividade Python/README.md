# Atividade Python

Esta pasta contém uma série de exercícios de programação em Python desenvolvidos no âmbito da unidade curricular de Linguagens e Paradigmas da Programação.

## Estrutura dos Exercícios

A atividade está dividida em 5 exercícios distintos, cada um focando em diferentes conceitos de programação:

### Exercício 1 - Conversão de Idade
- **Ficheiro**: `Exercício 1/Idade_anos_em_dias.py`
- **Conceitos**: Entrada de dados, operações matemáticas, formatação de saída
- **Descrição**: Converte idade expressa em anos, meses e dias para apenas dias

### Exercício 2 - Categorização de Atletas
- **Ficheiro**: `Exercício 2/categoria_atleta.py`
- **Conceitos**: Estruturas condicionais (if/elif/else)
- **Descrição**: Determina a categoria de um atleta baseada na sua idade

### Exercício 3 - Aprovação de Alunos
- **Ficheiro**: `Exercício 3/aprovação_do_aluno.py`
- **Conceitos**: Validação de dados, estruturas condicionais aninhadas
- **Descrição**: Determina a situação de um aluno (Aprovado/Exame/Reprovado) baseada na assiduidade e nota

### Exercício 4 - Comparação de Pessoas
- **Ficheiro**: `Exercício 4/mais_alta_e_pesada.py`
- **Conceitos**: Ciclos (for), estruturas de dados, comparações
- **Descrição**: Regista dados de duas pessoas e identifica a mais alta e a mais pesada

### Exercício 5 - Zodíaco Chinês
- **Ficheiro**: `Exercício 5/Zodiaco_Chinês.py`
- **Conceitos**: Listas, operações matemáticas (módulo), indexação
- **Descrição**: Determina o signo do zodíaco chinês baseado no ano de nascimento

## Como Executar

Para executar qualquer um dos exercícios:

1. Navegue até à pasta do exercício desejado
2. Execute o ficheiro Python:
   ```bash
   python nome_do_ficheiro.py
   ```
3. Siga as instruções apresentadas no ecrã

## Requisitos

- Python 3.x
- Nenhuma biblioteca externa necessária (apenas bibliotecas padrão)
