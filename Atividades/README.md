## Estrutura

### Atividade 1 - Comparação Python vs Java

Esta atividade compara a implementação de um algoritmo em Python e Java, demonstrando as diferenças entre as duas linguagens.

#### Conteúdo

- **Código/**
  - `actcomentado.py` - Implementação em Python com comentários detalhados
  - `teste.java` - Implementação em Java
- **Relatório/**
  - `Atividade Python vs Java_MiguelMagalhaes.pdf` - Relatório comparativo
  - `DOCX/` - Versão em formato Word do relatório

#### Descrição do Algoritmo

O algoritmo implementado solicita o nome de um aluno e as suas notas, verificando se as notas são válidas (entre 0 e 20). Os dados são armazenados num dicionário (Python) ou estrutura equivalente (Java) e são exibidas as informações verificadas, incluindo o cálculo da média.

#### Conceitos Demonstrados

- **Python**: Dicionários, listas, tratamento de exceções, ciclos `while`, validação de dados
- **Java**: Classes, métodos, arrays, tratamento de exceções, ciclos `while`, validação de dados

#### Como Executar

**Python:**
```bash
cd "Atividade 1/Código"
python actcomentado.py
```

**Java:**
```bash
cd "Atividade 1/Código"
javac teste.java
java teste
```

#### Funcionalidades

1. Solicita o nome do aluno
2. Permite inserir múltiplas notas (termina com 'fim')
3. Valida se as notas estão entre 0 e 20
4. Calcula e exibe a média das notas
5. Trata erros de entrada inválida
